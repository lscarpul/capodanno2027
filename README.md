# Capodanno 2027

Landing page (React + Tailwind, build con Vite) e app di check-in alla porta.

- `/` → landing (`src/Capodanno2027.jsx`, dati del party e del bonifico in cima al file)
- `/checkin/porta.html` → app porta (fuori da Claude gira in modalità demo, dati solo sul dispositivo)

Sviluppo: `npm install && npm run dev`. Ogni push su `main` pubblica su GitHub Pages tramite `.github/workflows/deploy.yml`.
